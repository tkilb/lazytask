# lazytask

A TUI frontend for the [Taskwarrior](https://taskwarrior.org/) CLI, written in Go using [Bubble Tea](https://github.com/charmbracelet/bubbletea), with a lazygit-inspired panel layout.

## Requirements

- Go 1.22+
- [Taskwarrior](https://taskwarrior.org/) CLI (`task`)

## Running

```bash
go run ./cmd/lazytask
```

## Testing

```bash
go test ./...
```
